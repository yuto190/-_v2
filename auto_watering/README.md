# 土壌水分センサー連動 自動散水システム（100V電源なし・電池駆動）

```
水道 → 蛇口 → [電動ボールバルブ 9–24V] → ホース/点滴チューブ → 植物
                     ↑ TB67H450（Hブリッジ）
                     ↑ 12V ← TPS61088 昇圧（弁を動かす数秒間だけON）
              [XIAO ESP32C3] ← 静電容量式土壌水分センサー
                     ↑
              18650 Li-ion ×1（USB-C 充電、任意でソーラー）
```

### 1.1 Raspberry Pi Zero を選ばない理由

| 項目 | Pi Zero (2) W | ESP32-C3 (XIAO) |
|---|---|---|
| 待機電流 | 約100 mA 常時（スリープ不可） → 2,400 mAh/日 | 約0.044 mA（ディープスリープ） |
| ADC | なし（外付け要） | 内蔵 12bit |
| 突然の電源断 | SDカード破損のリスク | フラッシュ上のJSONのみ、問題なし |
| 起動時間 | 30秒以上 | 1秒未満 |

100Vが無く電池運用である以上、Pi Zero は不適。Wi‑Fi 経由の設定変更やログ閲覧は ESP32 でも十分できる。

### 1.2 ESP32-DevKitC-32E（秋月 115673、¥1,800）について

机上での開発・USB給電で常設するなら問題ない。ただし基板上のUSBシリアル変換IC（CP2102）と
レギュレーター（AMS1117）がディープスリープ中も数mA消費するため、電池運用には向かない。
本ファームウェアは `config.json` の `pins` を変えるだけで DevKitC でも動く（後述）。

## 2. 弁の選定

### 2.1 購入時のチェックリスト（9–24V / 12V 品）

| 項目 | 選ぶもの | 避けるもの |
|---|---|---|
| 制御方式 | **CR-02（3線2制御）**。CR-01（2線・極性反転）も可。CR-05（5線・位置フィードバック付き）はフィードバック線を使わなければ CR-02 と同じ | **CR-03（3線1制御）、CR-04（2線・通電中のみ開）、「電源断時自動復帰」型**。いずれも開状態の保持に常時通電が必要で電池が持たない |
| 電圧 | **DC12V**、または **9–24V AC/DC** | AC220V 専用品 |
| ねじ | **G1/2（BSP）**。日本のホース金具（管用平行ねじ G1/2）と合う | NPT 1/2（米国規格のテーパーねじ）。米国 US Solid 製品に多い。使うなら変換継手が必要 |
| 口径 | 1/2インチ（DN15） | 1インチ以上は消費電力が大きい（最大5 W・6〜8秒） |
| 材質 | 真鍮またはステンレス | |

US Solid の公表値では、1/2〜3/4 インチの 9–24V 品は開閉 3〜5 秒・最大 2 W で、
開閉が終われば消費電力はゼロになる。ほかの CR-02 品もおおむね同等。

### 2.2 配線色について

**配線色はメーカーごとに異なる**。US Solid は「黄＝共通（−）、赤に＋で開、青に＋で閉」だが、
別の色割り当ての製品もある。本体ラベルか説明書で **COM（共通）/ OPEN（ON）/ CLOSE（OFF）** を確認し、
次のように接続する。

| 弁の線 | 接続先 |
|---|---|
| COM（共通） | GND |
| OPEN | TB67H450 **OUT1** |
| CLOSE | TB67H450 **OUT2** |

CR-01（2線）の場合は 2 本を OUT1 / OUT2 に直接つなぐ。開く向きが逆なら 2 本を入れ替える。
AC/DC 兼用品は内部に整流回路を持つものが多いが、上の接続（COM=GND、OPEN/CLOSE に +12V）で動作する。

### 2.3 他の方式との比較

| 案 | 種類 | 保持電力 | 電源 | 入手性 | 備考 |
|---|---|---|---|---|---|
| **A（推奨）** | 電動ボールバルブ CR-02 **9–24V/12V** | 0 | 18650 → 12V 昇圧 | ◎ | 本設計 |
| A' | 電動ボールバルブ CR-02 **DC3–6V/5V** | 0 | 18650 直結（昇圧不要） | △ | 見つかれば部品が減る。弁ドライバを DRV8835（秋月 109848）に替え、`valve_power_en` を `null` に |
| B | ラッチ式電磁弁 | 0 | パルス数十ms | △ | `valve.type = latch_2wire` |
| C | 常時閉(NC)電磁弁 12V | 連続 0.3〜0.5 A | 12V | ◎ | 3分散水で約25 mAh 以上。電池向きでない。`valve.type = nc_mosfet` |

秋月電子は水用の電磁弁・ボールバルブを扱っていない（検索で該当なし）。弁だけは Amazon 等で購入する。

## 3. 電源設計

### 3.1 構成: 18650 ×1 → XIAO ＋ 12V 昇圧（間欠運転）

- XIAO ESP32C3 裏面の **BAT+ / BAT−** パッドに電池を接続。USB-C を挿すと内蔵充電器（約350 mA）で充電される。
- **TPS61088 モジュールの VIN も電池から直接**とる。出力は可変抵抗で **12.0 V** に合わせる（調整範囲 4.7〜12.6 V）。
- TPS61088 モジュールの **EN 端子は基板上で 100 kΩ により VIN へプルアップ**されている（未接続だと常時動作）。
  そのままではディープスリープ中に GPIO が高インピーダンスになり、昇圧が動き続けてしまう。
  そこで **EN–GND 間に 4.7 kΩ を追加**し、GPIO10 が H を出している間だけ動作させる。
  - 停止時の EN 電圧は 4.2 V × 4.7 / 104.7 ≒ 0.19 V。TPS61088 の EN 閾値（L ≤ 0.4 V）を下回る。
  - この分圧に流れる電流は約 35〜40 µA（1日約0.9 mAh）。
- TPS61088 は停止中も入力と出力が内部ダイオード経由でつながる（出力 ≒ 電池電圧 − 0.4 V）。
  この電圧は TB67H450 の動作範囲（4.5 V 以上）を下回るので、ドライバは停止したまま。
  IN1=IN2=L のため弁には電流が流れない。
- 弁を動かすときの電池電流は、2 W ÷ 効率0.9 ÷ 3.5 V ≒ 0.65 A。起動時はその2倍程度になりうる。
  **必ず保護回路付きセル**（過放電・短絡保護）を使う。
- 夏季の直射日光下で40℃を超える場所にはケースを置かない。

### 3.2 電力収支（概算）

| 項目 | 条件 | 1日あたり |
|---|---|---|
| ディープスリープ | 44 µA × 24 h | 1.1 mAh |
| 昇圧 EN の分圧＋停止中リーク | 約 40 µA × 24 h | 1.0 mAh |
| 測定（10分毎、各3秒、約35 mA） | 144回/日 | 4.2 mAh |
| 弁の開閉（2 W × 5 s、効率0.9、3.7 V 換算で 1回 約0.83 mAh） | 開閉12回/日（散水3回 × 2サイクル × 開閉） | 10 mAh |
| 合計 | | **約 17 mAh/日** |

マージンを2倍見ても約 35 mAh/日。2,500 mAh なら **約2か月**。月1回のUSB-C充電で運用できる。

### 3.3 任意: ソーラー充電

- CN3791 MPPT 充電モジュール（6V入力版、Amazon 500〜900円）＋ 秋月「太陽電池モジュール 1.2W SY-M1.2W」（通販コード 131373、¥450）を電池に並列接続すると無充電運用が可能。
- CN3791 の BAT 出力と XIAO の BAT パッドを同じ電池につなぐ。XIAO の充電器は USB 接続時以外は動作しないので干渉しない。

### 3.4 代替: 12V 鉛蓄電池＋ソーラー（常設・複数系統向け）

12V の小型シール鉛蓄電池と 12V 系ソーラーパネル（秋月「太陽電池モジュール 5W」通販コード 114254 など）＋市販の PWM 充電コントローラーで 12V 系を作る方法もある。
この場合 TPS61088 は不要で、TB67H450 の VM に 12V を直接つなぎ、`valve_power_en` を `null` にする。
XIAO へは待機電流の小さい 5V 降圧 DCDC を介して 5V ピンへ給電する。重く大きくなるので、鉢数個なら 3.1 の構成で十分。

## 5. 配線

### 5.1 ピン割り当て（XIAO ESP32C3）

| XIAO ピン | GPIO | 用途 | config.json |
|---|---|---|---|
| D1 (A1) | 3 | センサー出力（アナログ入力） | `pins.sensor_adc` |
| D2 (A2) | 4 | 電池電圧（100k:100k 分圧、任意） | `pins.battery_adc` |
| D3 | 5 | センサー電源（測定時だけ H、約5 mA） | `pins.sensor_power` |
| D4 | 6 | TB67H450 **IN1**（OUT1=開） | `pins.valve_a` |
| D5 | 7 | TB67H450 **IN2**（OUT2=閉） | `pins.valve_b` |
| D10 | 10 | TPS61088 **EN**（H で 12V 出力） | `pins.valve_power_en` |
| D7 | 20 | 設定ボタン（GNDへ、内部プルアップ） | `pins.config_button` |
| D6 | 21 | LED（1 kΩ 経由で GND） | `pins.led` |
| 3V3 | — | TB67H450 VREF（説明書に従う） | |
| BAT+/BAT− | — | 18650（裏面パッド） | |

ESP32-C3 のストラップピン（GPIO2, 8, 9）は使わないようにしてある（起動不良の回避）。
D0/GPIO2、D8/GPIO8、D9/GPIO9 は空けておくこと。
D6/GPIO21 は起動直後にシリアル出力が出るので、LED が一瞬ちらつくことがあるが問題ない。

### 5.2 結線図

```
 18650(+) ──┬──────────────────────── XIAO BAT+
            ├──────────────────────── TPS61088 VIN
            ├─[470µF 10V]─ GND
            └─[100kΩ]─┬─[100kΩ]─ GND        （任意）電池監視 → D2 (GPIO4)
                      └────────────────────► D2
 18650(−) ──────────── GND（全GNDを1点に集める: XIAO BAT−, TPS61088 GND,
                            TB67H450 GND, センサー GND, 弁 COM）

 TPS61088 EN ◄───────────────────────── D10 (GPIO10)
             └─[4.7kΩ]─ GND             ← 必須。スリープ中に昇圧を確実に止める
 TPS61088 VOUT (12.0V) ──┬───────────── TB67H450 VM
                         └─[470µF 25V]─ GND

 TB67H450 IN1 ◄──────┬───────────────── D4 (GPIO6)
                     └─[10kΩ]─ GND
 TB67H450 IN2 ◄──────┬───────────────── D5 (GPIO7)
                     └─[10kΩ]─ GND
 TB67H450 VREF ◄──────────────────────── 3V3（説明書に従う）
 TB67H450 OUT1 ─────────────────────────► 弁 OPEN 線
 TB67H450 OUT2 ─────────────────────────► 弁 CLOSE 線
                                          弁 COM 線 ──► GND

 センサー VCC ◄────── D3 (GPIO5)    センサー AOUT ──► D1 (GPIO3)    センサー GND ── GND
 タクトSW: D7 (GPIO20) ── SW ── GND
 LED:      D6 (GPIO21) ──[1kΩ]──[LED]── GND
```

動作の順序（ファームウェアが自動で行う）:

1. GPIO10 = H で TPS61088 起動 → 100 ms 待つ（`valve.power_settle_ms`）
2. 開くとき IN1=H / IN2=L、閉じるとき IN1=L / IN2=H を `valve.travel_ms` の間出す
3. IN1=IN2=L に戻し、GPIO10 = L で昇圧停止

10 kΩ と 4.7 kΩ のプルダウンは、リセット中・ディープスリープ中に入力が浮いて弁が勝手に動くのを防ぐ。

### 5.3 組み立て後の確認手順

1. **弁をつなぐ前に** TPS61088 の EN を一時的に 3V3 へつなぎ、テスターで VOUT を見ながら可変抵抗を回して **12.0 V** に合わせる。終わったら EN を D10 の配線に戻す。
2. ファームウェアを書き込み、設定モード（6.3）で「弁を開く」「弁を閉じる」を押す。弁の開閉表示窓で動作を確認する。開閉が逆なら OPEN/CLOSE の線を入れ替える。
3. 開閉にかかる時間をストップウォッチで測り、`valve.travel_ms` を「実測 + 3 秒」程度にする（初期値 10,000 ms）。長すぎても弁内部のリミットスイッチで止まるので壊れないが、昇圧の動作時間がその分延びる。
4. 待機中（ディープスリープ中）の電池電流をテスターで測る。目安は **0.1 mA 以下**。これを大きく超える場合は EN のプルダウン抵抗とモジュールの接続を確認する。

### 5.4 ESP32-DevKitC-32E で使う場合

`config.json` の `pins` を例えば `sensor_adc: 34, battery_adc: 35, sensor_power: 25, valve_a: 26, valve_b: 27, valve_power_en: 32, config_button: 14, led: 2` に変更する。
GPIO34/35 は入力専用・ADC1 なのでアナログ入力に適する。USB給電（または 5V ピン）で運用。

## 6. ファームウェア

MicroPython 製。ユーザーがPython に慣れていることを前提に、設定・ロジック・ハードウェアを分離してある。

| ファイル | 内容 |
|---|---|
| `firmware/config.json` | **すべての調整項目**。しきい値、散水時間・休憩・回数、測定間隔、ピン、弁種別 |
| `firmware/main.py` | 起動 → 弁閉 → 設定モード判定 → 測定 → 判定 → 散水 → ディープスリープ |
| `firmware/logic.py` | 散水判定の純粋ロジック（ハードウェア非依存。PCで単体テスト可） |
| `firmware/hal.py` | センサー・弁（3種）・弁用昇圧電源のON/OFF・ボタン・LED・電池監視 |
| `firmware/webcfg.py` | Wi‑Fi 設定モード（スマホから設定変更、弁テスト、ログ閲覧、時計合わせ） |
| `firmware/store.py` | config/state/log のフラッシュ保存 |
| `tests/test_logic.py`, `tests/test_hal.py` | `python3 -m unittest auto_watering/tests/test_logic.py auto_watering/tests/test_hal.py` でPC上で検証（判定ロジックと、昇圧ON→弁駆動→昇圧OFF の順序） |

### 6.1 要求仕様への対応

| 要求 | 実装 |
|---|---|
| ① しきい値を後から変更 | `threshold_on_pct`（散水開始）, `threshold_off_pct`（散水途中の打ち切り）。Wi‑Fi 画面または `config.json` 編集で変更、再コンパイル不要 |
| ② 散水時間・インターバルを後から変更 | `watering.spray_sec` / `pause_sec` / `repeats`。初期値は **180秒散水 → 300秒休憩 → 180秒散水** |
| ③ しきい値到達後、少し待ってから散水 | `dry_confirm_delay_min`（初期値 60 分）。待ち時間中に湿れば（雨など）キャンセルされ、乾燥判定はやり直し |
| 根腐れ防止 | `min_interval_between_waterings_min`（初期 6 時間）、`max_waterings_per_day`（初期 3 回）、各散水後の再測定で `threshold_off_pct` 以上なら残りを中止 |
| 測定間隔 | `measure_interval_min`（初期 10 分）。この間はディープスリープ |
| 時間帯制限（任意） | `allowed_hours: [5, 10]` のように指定。時計を合わせたときだけ有効 |
| 電池保護（任意） | `battery.enabled: true` で分圧監視し、`low_battery_mv` 未満なら散水しない |

### 6.2 判定の流れ（`logic.plan`）

```
測定値 pct ≥ threshold_on  → WET（dry_since をクリア）
pct < threshold_on かつ dry_since 未設定 → dry_since = 今 → DRY_WAIT
経過 < dry_confirm_delay → DRY_WAIT
前回散水終了から < min_interval → COOLDOWN
本日の回数 ≥ max_waterings_per_day → DAILY_LIMIT
allowed_hours の外（時計設定時のみ） → OUTSIDE_HOURS
電池電圧 < low_battery_mv（監視有効時のみ） → LOW_BATTERY
それ以外 → WATER
```

散水シーケンス: `spray_sec` 開 → 閉 → `pause_sec` 待機 → … を `repeats` 回。
散水中はボタン2秒長押しで中断。弁は `try/finally` でどの経路でも必ず閉じる。
電源投入・リセット時（ディープスリープ復帰以外）は、散水途中で落ちた可能性に備えて**必ず弁を閉じてから**開始する。
`max_spray_sec_hard_limit`（初期 900 秒）を超える散水時間は設定しても切り詰められる。

### 6.3 設定の変え方

**方法A: Wi‑Fi 設定モード（スマホで完結）**

1. 設定ボタンを押したまま XIAO の RESET ボタンを押す（LED が1秒毎に点滅）。
2. スマホの Wi‑Fi で `watering-setup`（パスワード `mizuyari123`、`config.json` で変更可）に接続。
3. ブラウザで `http://192.168.4.1/` を開く。
   - 現在の水分 %・センサー mV・電池電圧・状態・直近ログ
   - しきい値、散水時間/休憩/回数、待ち時間、測定間隔 → **保存**
   - **弁を開く / 閉じる**（動作確認）、**今すぐ1サイクル散水**、**時刻合わせ**
   - 詳細設定（JSON 全体の編集）
4. 「設定モード終了」を押すか、10 分無操作で通常動作に戻る。

**方法B: USB で `config.json` を書き換える**

```
pip install mpremote
mpremote cp firmware/config.json :config.json
mpremote reset
```

### 6.4 書き込み手順

1. MicroPython 公式サイトから **ESP32_GENERIC_C3** の最新 `.bin` を取得。
2. XIAO の **BOOT ボタンを押しながら** USB-C を接続（書き込みモード）。
3. 書き込み:
   ```
   pip install esptool mpremote
   esptool.py --chip esp32c3 erase_flash
   esptool.py --chip esp32c3 --baud 460800 write_flash -z 0x0 ESP32_GENERIC_C3-<version>.bin
   ```
4. ファイル転送（`auto_watering/firmware` で実行）:
   ```
   mpremote cp boot.py main.py logic.py hal.py store.py webcfg.py config.json :
   mpremote reset
   ```
5. 開発中は `config.json` に `"debug_no_sleep": true, "debug_no_wdt": true` を追加すると
   ディープスリープせず USB が切れないので `mpremote repl` でログを見られる。

**レスキュー**: ディープスリープ中は USB が認識されない。設定ボタンを押しながらリセットすれば
10 分間起きているので、その間に `mpremote` で接続できる。

### 6.5 センサーのキャリブレーション（必須）

静電容量式の % は絶対値ではなく、土の種類・締まり・温度で変わる相対値。**鉢ごとに**行う。

1. 設定モードで画面を開き、センサーを**空気中**に置いて表示される mV を `raw_dry_mv` に入力。
2. センサーを**コップの水**に線まで浸し、表示 mV を `raw_wet_mv` に入力（3.3V 給電ではおおよそ 2,000〜2,300 mV と 1,000〜1,300 mV）。
3. 鉢に挿して、たっぷり潅水した直後の % と、植物がしおれ始める直前の % をログで確認し、
   `threshold_on_pct` をその中間〜やや乾き側に置く。初期値 35% は目安にすぎない。

## 7. 設置上の注意

- **センサー**: 基板上部（部品面と配線の接続部）は防水ではない。熱収縮チューブ＋ホットボンドまたはエポキシで覆う。根鉢の中、点滴の落下点から数cm離して、線まで挿す。
- **弁**: 水道直結なら真鍮製ボールバルブで問題ないが、**冬季は凍結で破損**するので水抜きする。蛇口は使用時のみ開ける運用（夜間に水圧をかけたままにしない）でも動作は変わらない。
- **フェイルセーフ**: 弁が開いたまま固着する故障は原理的に起こりうる。長期不在時は蛇口側に市販の乾電池式水やりタイマーを直列に入れて「1日1回・最大20分だけ開く」ように二重化すると安全。
- **ケース**: IP65 ケースに入れ、日陰に置く。ケーブル引き込みはグロメットかケーブルグランドで。
- **Li-ion**: 保護回路付きセル、高温を避ける、充電は目の届くところで。
- **乾燥判定の待ち時間**（③）: 初期 60 分。根の呼吸を促したいなら 120〜180 分に、乾燥に弱い植物なら 15〜30 分に。
