# 土壌水分センサー連動 自動散水システム（100V電源なし・電池駆動）

```
水道 → 蛇口 → [電動ボールバルブ] → ホース/点滴チューブ → 植物
                     ↑ DRV8835
              [XIAO ESP32C3] ← 静電容量式土壌水分センサー
                     ↑
              18650 Li-ion ×1（USB-C 充電、任意でソーラー）
```

### 1.1 Raspberry Pi Zero を選ばない理由

| 項目 | Pi Zero (2) W | ESP32-C3 (XIAO) |
|---|---|---|
| 待機電流 | 約100 mA 常時（スリープ不可） → 2,400 mAh/日 | 約0.044 mA（ディープスリープ） |
| ADC | なし（外付け要） | 内蔵 12bit |
| 突然の電源断 | SDカード破損のリスク | フラッシュ上のJSONのみ、問題なし |
| 起動時間 | 30秒以上 | 1秒未満 |

100Vが無く電池運用である以上、Pi Zero は不適。Wi‑Fi 経由の設定変更やログ閲覧は ESP32 でも十分できる。

### 1.2 ESP32-DevKitC-32E（秋月 115673、¥1,800）について

机上での開発・USB給電で常設するなら問題ない。ただし基板上のUSBシリアル変換IC（CP2102）と
レギュレーター（AMS1117）がディープスリープ中も数mA消費するため、電池運用には向かない。
本ファームウェアは `config.json` の `pins` を変えるだけで DevKitC でも動く（後述）。

## 2. 弁の選定（3案比較）

| 案 | 種類 | 保持電力 | 電圧 | 水圧 | 入手 | 備考 |
|---|---|---|---|---|---|---|
| **A（推奨）** | 電動ボールバルブ CR-02（3線式） | **0** | DC3–6V 品あり | 〜1.0 MPa | Amazon/AliExpress | 動作時 <100 mA〜数百mA、3〜8秒。内蔵リミットスイッチで自動停止。真鍮製で水道直結可 |
| B | ラッチ式（自己保持）電磁弁 | **0** | 3〜4V パルス 20〜50 ms | 製品次第 | 国内では農業用（アクアネットプラス等）か海外通販。入手性がやや悪い | 市販の乾電池式水やりタイマーの内部弁と同方式。極性反転パルスで開閉 |
| C | 常時閉(NC)直動電磁弁 | **連続 0.3〜0.5 A** | DC12V が主流 | 0.02–0.8 MPa | Amazon/モノタロウ（1,000〜2,000円） | 3分散水で約25 mAh。12V電池が別途必要。弁が発熱。最低水圧が必要（タンク落差では開かない製品あり） |

秋月電子は水用の電磁弁・ボールバルブを扱っていない（検索で該当なし）。弁は Amazon 等で
「電動ボールバルブ 1/2 DC3-6V CR02」で探す。**電圧仕様は "DC3-6V" または "DC5V" のものを選ぶ**
（Li-ion 1本 3.0〜4.2V で直接駆動するため。9–24V 品は不可）。

CR-02 の配線（DC運転時）: **黄＝共通（−）、赤に＋で開、青に＋で閉。到達後は無通電で状態保持。**

ファームウェアは `config.json` の `valve.type` を `ball_3wire` / `latch_2wire` / `nc_mosfet` に
切り替えるだけで3案すべてに対応する。

## 3. 電源設計

### 3.1 推奨: 18650 ×1 ＋ XIAO 内蔵充電器

- XIAO ESP32C3 裏面の **BAT+ / BAT−** パッドに電池を接続。USB-C を挿すと内蔵充電器（約350 mA）で充電される。
- 弁用モータードライバ（DRV8835）の **VM も電池から直接**（2〜11V対応）。
- **必ず保護回路付きセル**（過放電・短絡保護）を使う。夏季の直射日光下で40℃超になる場所にはケースを置かない。

### 3.2 電力収支（概算）

| 項目 | 条件 | 1日あたり |
|---|---|---|
| ディープスリープ | 44 µA × 24 h | 1.1 mAh |
| 測定（10分毎、各3秒、約35 mA） | 144回/日 | 4.2 mAh |
| 弁の開閉（0.3 A × 8 s × 開閉2回 × 散水4回/日） | 最大側の見積り | 5.3 mAh |
| 合計 | | **約 11 mAh/日** |

マージンを3倍見ても 30 mAh/日。2,500 mAh なら **2〜3か月**。月1回のUSB-C充電で運用できる。

### 3.3 任意: ソーラー充電

- CN3791 MPPT 充電モジュール（6V入力版、Amazon 500〜900円）＋ 秋月「太陽電池モジュール 1.2W SY-M1.2W」（通販コード 131373、¥450）を電池に並列接続すると無充電運用が可能。
- CN3791 の BAT 出力と XIAO の BAT パッドを同じ電池につなぐ。XIAO の充電器は USB 接続時以外は動作しないので干渉しない。

### 3.4 代替: モバイルバッテリー

休止電流が小さいと自動で出力を切る製品が多い。「低電流モード」「常時給電」をうたう製品なら XIAO の
USB-C に挿すだけで動く（この場合 BAT パッドは未接続）。試験運用には手軽。

## 5. 配線

### 5.1 ピン割り当て（XIAO ESP32C3）

| XIAO ピン | GPIO | 用途 | config.json |
|---|---|---|---|
| D1 (A1) | 3 | センサー出力（アナログ入力） | `pins.sensor_adc` |
| D2 (A2) | 4 | 電池電圧（100k:100k 分圧、任意） | `pins.battery_adc` |
| D3 | 5 | センサー電源（測定時だけ H、約5 mA） | `pins.sensor_power` |
| D4 | 6 | DRV8835 **AIN1**（弁 A） | `pins.valve_a` |
| D5 | 7 | DRV8835 **AIN2**（弁 B） | `pins.valve_b` |
| D7 | 20 | 設定ボタン（GNDへ、内部プルアップ） | `pins.config_button` |
| D10 | 10 | LED（1 kΩ 経由で GND） | `pins.led` |
| 3V3 | — | センサー VCC は使わない（GPIO5 から給電）、DRV8835 **VCC**（ロジック） | |
| BAT+/BAT− | — | 18650（裏面パッド） | |

ESP32-C3 のストラップピン（GPIO2, 8, 9）は使わないようにしてある（起動不良の回避）。
D0/GPIO2 は空けておくこと。

### 5.2 結線図

```
                         ┌──────────────────────┐
   18650 (+) ────┬───────┤ BAT+     XIAO ESP32C3 │
   18650 (−) ────┼───┬───┤ BAT−                 │
                 │   │   │  3V3 ├───────────────┼──► DRV8835 VCC
                 │   │   │  GND ├───────────────┼──► DRV8835 GND, センサー GND
                 │   │   │  D3 (GPIO5) ├────────┼──► センサー VCC（給電スイッチ）
                 │   │   │  D1 (GPIO3) ◄────────┼─── センサー AOUT
                 │   │   │  D4 (GPIO6) ├──┬─────┼──► DRV8835 AIN1
                 │   │   │  D5 (GPIO7) ├──┼─┬───┼──► DRV8835 AIN2
                 │   │   │  D7 (GPIO20)├──┼─┼─[タクトSW]─ GND
                 │   │   │  D10(GPIO10)├──┼─┼─[1kΩ]─[LED]─ GND
                 │   │   └─────────────┼──┼─┼────┘
                 │   │     10kΩ ───────┘  │ │  （プルダウン ×2、GNDへ）
                 │   │     10kΩ ──────────┘ │
                 │   │                      │
                 │   │   ┌──────────────────┴───┐
                 ├───┼───┤ VM        DRV8835     │   470〜1000µF を VM–GND 間に
                 │   └───┤ GND     (MODE → GND)  │
                 │       │ AOUT1 ├──────────────► 弁 赤（＋で開）
                 │       │ AOUT2 ├──────────────► 弁 青（＋で閉）
                 │       └───────┘                弁 黄 ──► GND
                 │
   （任意）電池監視: 18650(+) ─[100kΩ]─┬─[100kΩ]─ GND
                                       └──► D2 (GPIO4)
```

- DRV8835 の **MODE ピンは GND**（IN/IN モード）。AIN1=H/AIN2=L で AOUT1=H、AIN1=L/AIN2=H で AOUT2=H。
- 10 kΩ プルダウンは、リセット中・ディープスリープ中に入力が浮いて弁が勝手に動くのを防ぐ保険。
- **ラッチ式電磁弁（2線）** のときは AOUT1/AOUT2 に弁の2線をつなぐ（極性は試して `valve_a` で開く向きに）。
- **NC電磁弁（案C）** のときは DRV8835 を使わず、GPIO6 → 2SK4017 ゲート（直列 100 Ω、10 kΩ プルダウン）、
  ドレイン → 弁(−)、弁(+) → 12V、ソース → GND、弁と並列に 1N4007（カソードを＋側）。

### 5.3 ESP32-DevKitC-32E で使う場合

`config.json` の `pins` を例えば `sensor_adc: 34, battery_adc: 35, sensor_power: 25, valve_a: 26, valve_b: 27, config_button: 14, led: 2` に変更する。
GPIO34/35 は入力専用・ADC1 なのでアナログ入力に適する。USB給電（または 5V ピン）で運用。

## 6. ファームウェア

MicroPython 製。ユーザーがPython に慣れていることを前提に、設定・ロジック・ハードウェアを分離してある。

| ファイル | 内容 |
|---|---|
| `firmware/config.json` | **すべての調整項目**。しきい値、散水時間・休憩・回数、測定間隔、ピン、弁種別 |
| `firmware/main.py` | 起動 → 弁閉 → 設定モード判定 → 測定 → 判定 → 散水 → ディープスリープ |
| `firmware/logic.py` | 散水判定の純粋ロジック（ハードウェア非依存。PCで単体テスト可） |
| `firmware/hal.py` | センサー・弁（3種）・ボタン・LED・電池監視 |
| `firmware/webcfg.py` | Wi‑Fi 設定モード（スマホから設定変更、弁テスト、ログ閲覧、時計合わせ） |
| `firmware/store.py` | config/state/log のフラッシュ保存 |
| `tests/test_logic.py` | `python3 -m unittest auto_watering/tests/test_logic.py` でPC上で検証 |

### 6.1 要求仕様への対応

| 要求 | 実装 |
|---|---|
| ① しきい値を後から変更 | `threshold_on_pct`（散水開始）, `threshold_off_pct`（散水途中の打ち切り）。Wi‑Fi 画面または `config.json` 編集で変更、再コンパイル不要 |
| ② 散水時間・インターバルを後から変更 | `watering.spray_sec` / `pause_sec` / `repeats`。初期値は **180秒散水 → 300秒休憩 → 180秒散水** |
| ③ しきい値到達後、少し待ってから散水 | `dry_confirm_delay_min`（初期値 60 分）。待ち時間中に湿れば（雨など）キャンセルされ、乾燥判定はやり直し |
| 根腐れ防止 | `min_interval_between_waterings_min`（初期 6 時間）、`max_waterings_per_day`（初期 3 回）、各散水後の再測定で `threshold_off_pct` 以上なら残りを中止 |
| 測定間隔 | `measure_interval_min`（初期 10 分）。この間はディープスリープ |
| 時間帯制限（任意） | `allowed_hours: [5, 10]` のように指定。時計を合わせたときだけ有効 |
| 電池保護（任意） | `battery.enabled: true` で分圧監視し、`low_battery_mv` 未満なら散水しない |

### 6.2 判定の流れ（`logic.plan`）

```
測定値 pct ≥ threshold_on  → WET（dry_since をクリア）
pct < threshold_on かつ dry_since 未設定 → dry_since = 今 → DRY_WAIT
経過 < dry_confirm_delay → DRY_WAIT
前回散水終了から < min_interval → COOLDOWN
本日の回数 ≥ max_waterings_per_day → DAILY_LIMIT
allowed_hours の外（時計設定時のみ） → OUTSIDE_HOURS
電池電圧 < low_battery_mv（監視有効時のみ） → LOW_BATTERY
それ以外 → WATER
```

散水シーケンス: `spray_sec` 開 → 閉 → `pause_sec` 待機 → … を `repeats` 回。
散水中はボタン2秒長押しで中断。弁は `try/finally` でどの経路でも必ず閉じる。
電源投入・リセット時（ディープスリープ復帰以外）は、散水途中で落ちた可能性に備えて**必ず弁を閉じてから**開始する。
`max_spray_sec_hard_limit`（初期 900 秒）を超える散水時間は設定しても切り詰められる。

### 6.3 設定の変え方

**方法A: Wi‑Fi 設定モード（スマホで完結）**

1. 設定ボタンを押したまま XIAO の RESET ボタンを押す（LED が1秒毎に点滅）。
2. スマホの Wi‑Fi で `watering-setup`（パスワード `mizuyari123`、`config.json` で変更可）に接続。
3. ブラウザで `http://192.168.4.1/` を開く。
   - 現在の水分 %・センサー mV・電池電圧・状態・直近ログ
   - しきい値、散水時間/休憩/回数、待ち時間、測定間隔 → **保存**
   - **弁を開く / 閉じる**（動作確認）、**今すぐ1サイクル散水**、**時刻合わせ**
   - 詳細設定（JSON 全体の編集）
4. 「設定モード終了」を押すか、10 分無操作で通常動作に戻る。

**方法B: USB で `config.json` を書き換える**

```
pip install mpremote
mpremote cp firmware/config.json :config.json
mpremote reset
```

### 6.4 書き込み手順

1. MicroPython 公式サイトから **ESP32_GENERIC_C3** の最新 `.bin` を取得。
2. XIAO の **BOOT ボタンを押しながら** USB-C を接続（書き込みモード）。
3. 書き込み:
   ```
   pip install esptool mpremote
   esptool.py --chip esp32c3 erase_flash
   esptool.py --chip esp32c3 --baud 460800 write_flash -z 0x0 ESP32_GENERIC_C3-<version>.bin
   ```
4. ファイル転送（`auto_watering/firmware` で実行）:
   ```
   mpremote cp boot.py main.py logic.py hal.py store.py webcfg.py config.json :
   mpremote reset
   ```
5. 開発中は `config.json` に `"debug_no_sleep": true, "debug_no_wdt": true` を追加すると
   ディープスリープせず USB が切れないので `mpremote repl` でログを見られる。

**レスキュー**: ディープスリープ中は USB が認識されない。設定ボタンを押しながらリセットすれば
10 分間起きているので、その間に `mpremote` で接続できる。

### 6.5 センサーのキャリブレーション（必須）

静電容量式の % は絶対値ではなく、土の種類・締まり・温度で変わる相対値。**鉢ごとに**行う。

1. 設定モードで画面を開き、センサーを**空気中**に置いて表示される mV を `raw_dry_mv` に入力。
2. センサーを**コップの水**に線まで浸し、表示 mV を `raw_wet_mv` に入力（3.3V 給電ではおおよそ 2,000〜2,300 mV と 1,000〜1,300 mV）。
3. 鉢に挿して、たっぷり潅水した直後の % と、植物がしおれ始める直前の % をログで確認し、
   `threshold_on_pct` をその中間〜やや乾き側に置く。初期値 35% は目安にすぎない。

## 7. 設置上の注意

- **センサー**: 基板上部（部品面と配線の接続部）は防水ではない。熱収縮チューブ＋ホットボンドまたはエポキシで覆う。根鉢の中、点滴の落下点から数cm離して、線まで挿す。
- **弁**: 水道直結なら真鍮製ボールバルブで問題ないが、**冬季は凍結で破損**するので水抜きする。蛇口は使用時のみ開ける運用（夜間に水圧をかけたままにしない）でも動作は変わらない。
- **フェイルセーフ**: 弁が開いたまま固着する故障は原理的に起こりうる。長期不在時は蛇口側に市販の乾電池式水やりタイマーを直列に入れて「1日1回・最大20分だけ開く」ように二重化すると安全。
- **ケース**: IP65 ケースに入れ、日陰に置く。ケーブル引き込みはグロメットかケーブルグランドで。
- **Li-ion**: 保護回路付きセル、高温を避ける、充電は目の届くところで。
- **乾燥判定の待ち時間**（③）: 初期 60 分。根の呼吸を促したいなら 120〜180 分に、乾燥に弱い植物なら 15〜30 分に。
